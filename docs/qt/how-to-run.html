How to run

Windows

Unzip the zip file and navigate to the generated folder. Double-click on 'elpida-qt.exe' file to start Elpida.

Linux

Double-click on 'Elpida-latest-xxx.Qt.appimage' (where xxx is the architecture). It should start elpida immediately. If it does not start, make sure the file has execute rights. If it has execute rights and still does not start, run it via command line and check the output.

Getting consistent results

Scores can vary between runs when the operating system changes the CPU speed while the benchmarks run. On some machines, especially older ones, this can make single benchmarks run at half speed or less in one run and at full speed in the next.

  • Linux: Set the CPU frequency governor to 'performance' before running, for example with sudo cpupower frequency-set -g performance (the 'cpupower' tool is in the 'linux-tools' package on Ubuntu). The setting lasts until the next reboot.
  • Windows: Select the 'High performance' power plan in the power options.
  • Keep laptops connected to power.
  • Close other programs and let the machine idle while the benchmarks run.
